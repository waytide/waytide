# Reserve — manual page

```
RESERVE(1)                     Waytide Manual                     RESERVE(1)

NAME
     reserve - settle a word as a term, with a fixed meaning

SYNOPSIS
     /reserve <word>
     /reserve help

DESCRIPTION
     Waytide writes in a simplified technical English with an approved
     dictionary. Reserving a word adds it to a vocabulary as a term, with
     the meaning given there.

     The word goes through six steps: look it up in the dictionary, ask
     what it names, decide noun or verb, try a standard category, fall
     back to one of Waytide's own, and write the entry. The category is
     put to the engineer.

     Reserving a word changes what is written from then on. It does not
     rewrite text that already uses some other word.

EXAMPLES
     /reserve basket

SEE ALSO
     /ete
```
