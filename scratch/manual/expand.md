# Expand — manual page

```
EXPAND(1)                      Waytide Manual                      EXPAND(1)

NAME
     expand - expand the previous answer

SYNOPSIS
     /expand
     /expand help

DESCRIPTION
     An answer is given as a short list. Where the agent left detail out,
     it ends the answer with a line offering more. /expand gives the
     previous answer again in full, with the detail the list left out.

SEE ALSO
     /clarify
```
