# Clarify — manual page

```
CLARIFY(1)                     Waytide Manual                     CLARIFY(1)

NAME
     clarify - make the previous answer plainer

SYNOPSIS
     /clarify
     /clarify help

DESCRIPTION
     Rewrites the previous answer more plainly, then rewrites it plainly
     once more: the point first, in a sentence or two, then only the few
     facts needed to understand it and decide.

     It runs twice because the second pass often gives the more humane
     answer. The first pass clears out what the answer did not need. The
     second is written for the person reading it, in the words they would
     use themselves.

SEE ALSO
     /expand, /ete
```
