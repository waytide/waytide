# Ete — manual page

```
ETE(1)                         Waytide Manual                         ETE(1)

NAME
     ete - write in Eventide Technical English

SYNOPSIS
     /ete
     /ete help

DESCRIPTION
     Rewrites the response in Eventide Technical English: the approved
     dictionary and writing rules of Simplified Technical English, with
     Waytide's own reserved terms. Short sentences, active voice, no
     semicolons, and one idea to a sentence.

SEE ALSO
     /reserve, /clarify
```
