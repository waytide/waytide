SLASHER SKILLS

Usage: /<command> [<subcommand>] [<arguments>]
       A command typed with no subcommand asks which one is meant,
       except where a bare command has its own meaning, shown below.
       A bare /slasher prints the command domain table, one line for each
       command domain. /command-table prints it too, and /commands is an
       alias of /command-table. /slasher help prints this help.
