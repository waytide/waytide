# Loop record — STE Spec

The reading of the ASD-STE100 specification, run as an experiment on `experiment/ste-spec`. Its
question, forecast, and state are in the experiment record of the same name. This record carries
the cycles.

**Mode: attended.** The loop stops at every hinge.

## Cycle 1 — what the experiment tests

- **Hinge:** which question the experiment asks. Three readings were available: which extraction
  method preserves the document, whether the document can be read without installing software, and
  what the document says.
- **Options:** the three above, put through the selection interface. The third option's description
  stated its weakness before it was chosen: a descriptive question reaches no verdict, which the
  experiments-convention treats as a reason to write something other than an experiment.
- **Decision / chat:** **what does the specification say.** The developer chose it after the
  weakness was stated.
- **How the weakness is answered.** The record forecasts the specification's structure and content
  before the document is read. Ten predictions, each carrying a confidence. The gap between the
  forecast and the document is the finding. Extraction becomes a means rather than the question.

## Cycle 2 — how the work is conducted

- **Hinge:** the human's participation. The working location was not put, the branch having been created
  before the prompt.
- **Options:** attended and unattended.
- **Decision / chat:** **attended.**

## Cycle 3 — the branch topology has no rule

- **Hinge:** this experiment branches from another experiment's branch. The developer asked whether
  a rule covers that.
- **Options:** none put. The answer is a fact about the rules.
- **Decision / chat:** **no rule names a sub-branch.** `experiment-lifecycle` permits an upstream
  branch that is another topic branch, which makes the topology legal. No rule says what happens to
  this experiment if the parent is refuted, and no rule says whether a child may outlive its
  parent. The gap is recorded and does not block the work.
