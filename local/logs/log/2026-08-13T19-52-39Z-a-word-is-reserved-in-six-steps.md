# The sequence for reserving a word is written as a rule, `a-word-is-reserved-in-six-steps`, in the language package's `ste/` directory — look the word up in the STE dictionary, ask what it names and stop where it is ordinary vocabulary, decide noun or verb, try an STE category first, fall to an ETE category only where none holds, and write the entry in the vocabulary of the package whose domain the term belongs to; each step was already stated in one of three rules and the order was stated in none of them, so a writer reserving a word had to read all three and infer it, which is how a category gets picked by feel
