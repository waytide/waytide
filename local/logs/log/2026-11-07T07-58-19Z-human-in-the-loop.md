# Human in the loop — Unattended, selected by the engineer

**Tags:** [decision]

The question, put through the selection interface:

> Human in the loop
>
> - Agent's confidence: 55%. How sure the agent is that, working alone, it does the work as you would have it done.
> - Risk of redo: 45%. How likely it is that you will have to redo work the agent does. It is 100% minus the agent's confidence.
> - It'll work: 85%. How sure the agent is that what it builds alone works, and does what the work was started to do.
> - Your approval: 55%. How sure the agent is that it does what you would do: naming, shaping, and deciding things as you would.
>
> When the agent's confidence is 70% or lower, you may have to redo work the agent does.

The options:

- **Attended (Recommended)** — You decide. The agent automates.
- **Unattended** — The agent makes the decisions and generates through if you accept the plan it'll propose.

The engineer's answer: **Unattended**
