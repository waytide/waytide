# The session-start notice's last line becomes `Waytide's rules are loaded before your first instruction will be processed. To load them now, type: **load waytide**. Loading the rules will take a moment.` — the command names the read outright and is bold, retiring the contentless foil request `begin` set earlier the same day; the agent's `additionalContext` instruction names the same command, and the status line sets the repository name in bold as the subject the other segments annotate. What the named command gives up is attributability: with a contentless word a read that followed could only have come from the hook's channel, and with a command naming the read it could have come from either, so the channel is no longer testable from ordinary use — traded deliberately for a line a developer who has never seen the system can act on
