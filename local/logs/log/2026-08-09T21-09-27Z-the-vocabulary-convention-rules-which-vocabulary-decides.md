# foundation gains a vocabulary-convention rule — it states what a `vocabulary.md` holds (terms, substitutions, and discontinuations, which are two acts and not one), that a package gets a vocabulary only when its domain has specialized words so an absence is correct rather than missing, and the order the five vocabularies decide in: the STE dictionary with Waytide's reserved terms, then the `language` vocabulary, then a package vocabulary, then the project's own `local/rules/`. The more specific decides, because a domain knows its own words. A package that narrows a general term rather than contradicting it is specializing, and its entry must say which case it is
