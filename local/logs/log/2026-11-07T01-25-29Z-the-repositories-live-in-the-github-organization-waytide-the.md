# The repositories live in the GitHub organization waytide: the composite waytide/waytide, a repository per package such as waytide/foundation, and waytide/waytide-ruby. How are they renamed? — Rename the org, selected by the engineer

**Tags:** [decision]

The question, put through the selection interface:

> The repositories live in the GitHub organization waytide: the composite waytide/waytide, a repository per package such as waytide/foundation, and waytide/waytide-ruby. How are they renamed?

The options:

- **Rename the org** — Rename the organization waytide to slasher, the composite to slasher/slasher, and waytide-ruby to slasher-ruby. The package repositories keep their names, as slasher/foundation.
- **Org only** — Rename the organization waytide to slasher. Every repository keeps its name, so the composite becomes slasher/waytide.
- **New org** — Create a new slasher organization and transfer the repositories into it, renaming the composite and waytide-ruby. The waytide organization stays, empty.

The engineer's answer: **Rename the org**
