# The Waytide commands that would fit as skills are listed, for the Waytide skills item

These are the things an engineer types or asks for, according to the rules installed today. Nothing was built.

Commands with fixed words:

1. `status report`, or `project status`
2. `test report`
3. `test tree`
4. `new entry`
5. `New private journal entry`, `New private entry`, `Private note`
6. `Read private journal entries`, `Read private journal`
7. `show the timeline`, or `list the entries`
8. `Waytide reserves the word, X`
9. `Say it in ETE`
10. `begin collecting`, `end collecting`, `resume collecting`, settled in the recording item and not built

Requests with no fixed words:

11. a summary of the log
12. an expanded answer
13. writing or appending a work session record
14. declaring a package set
15. moving a private journal entry to the shared journal
16. starting a feature or an experiment
17. a release, where the next version is put to the engineer
18. publishing a package, by this repository's `CONTRIBUTING.md`

Scripts the engineer runs:

19. `install.sh`
20. `refresh-packages.sh`
21. `read-consuming-projects.sh`

Not a fit: `load waytide`, because it asks for the unconditional session-start read, which a skill would make conditional.
