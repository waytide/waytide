# The rule-reduction idea's plan is reordered to reach the derived files earlier and to end with the optional additionalContext experiment

The reducing-rule-files-to-their-essential-directives idea records the order, which is unbuilt and leaves the idea Open:

1. The starting point is measured.
2. An experiment tests whether a session that reads derived files reads faster and still honors the rules.
3. The engineer settles the open questions, with the experiment's findings in hand.
4. A feature builds one packaged script that prints every rule.
5. What is read is shrunk by the answer.
6. The read is measured again.
7. Optionally, an experiment tests whether the rules can arrive through the `additionalContext` channel, measured against the second measurement.

The derived files moved ahead of the settling, so their findings inform it. The `additionalContext` experiment moved to the end because, as the engineer stated it, it is ultimately optional and the framework will have the same functionality without that elaboration.
