# What should the summary under the /items table count for the items it does not list? — Count by state, selected by the engineer

**Tags:** [decision]

The question, put through the selection interface:

> What should the summary under the /items table count for the items it does not list?

The options:

- **Count by state** — One count for each state the table leaves out, such as Realized, Recorded, Abandoned, Done, Obsolete, Superseded, and Suspended.
- **Count by kind** — One count for each kind the items it leaves out have, such as Idea, Observation, and Design.

The engineer's answer: **Count by state**
