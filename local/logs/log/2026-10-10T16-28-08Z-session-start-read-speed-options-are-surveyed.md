# Options for a faster session-start read are surveyed against the rule-reduction idea, and none is adopted

The read measured 667,009 characters across 126 files. Provenance footers held 74,524 of them and the package `README.md` files 59,006.

Six options were named: reducing the files, reading a shorter derived artifact with the full files kept, printing the corpus from one packaged script to cut the tool calls, not reading deactivated packages, reading on demand rather than up front, and Claude Code's fast mode. The first two are open questions of the reducing-rule-files-to-their-essential-directives idea. The fourth and fifth would reverse what the a-project-declares-its-package-set rule and the announce-waytide-at-session-start rule settled.
