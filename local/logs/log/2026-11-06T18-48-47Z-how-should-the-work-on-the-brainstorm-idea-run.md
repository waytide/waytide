# How should the work on the /brainstorm idea run? — Directly on master, selected by the engineer

**Tags:** [decision]

The question, put through the selection interface:

> How should the work on the /brainstorm idea run?

The options:

- **As a feature** — Start a feature with its own record and branch, with the usual start selections: working location, participation, and verdict.
- **Directly on master** — Make the idea Active and do the change on master, with no feature record.

The engineer's answer: **Directly on master**
