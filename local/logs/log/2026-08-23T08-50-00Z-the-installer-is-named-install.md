# The composite's installer is named `install` rather than `install-all.sh` — the old name said it installs all of something and it now installs a named list, and a script is a command, so `./install` reads as one where `./install.sh` reads as a file being run; the shell-scripts-are-self-executable rule is widened from `.sh` files to shell scripts, since the bit and the shebang are what it asks for and neither depends on the name
