# Where should /command-table appear in the Slasher help and in the command table itself? — In the help header only, selected by the engineer

**Tags:** [decision]

The question, put through the selection interface:

> Where should /command-table appear in the Slasher help and in the command table itself?

The options:

- **Its own domain** — A new COMMAND TABLE help section and a new `/command-table` row in the table, as /load has its own.
- **In the LOAD domain** — Listed in the LOAD help section and named in the `/load` row, since both act at the start of a session.
- **In the help header only** — Named beside the bare /slasher in the help header as another way to print the table. No row in the table.

The engineer's answer: **In the help header only**
