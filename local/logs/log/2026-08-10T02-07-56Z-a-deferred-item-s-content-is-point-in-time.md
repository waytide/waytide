# A deferred item's own content is point-in-time and is not maintained — what it says was true when it was written, so a reference inside it that time has overtaken is not a defect and is not chased. The deferred-convention's reconciliation step is about artifacts pointing at an item, which is the other direction, and only that one is chased. What makes an item a queue entry rather than a permanent record is that it is deleted when it is resolved, not that its content is kept current
