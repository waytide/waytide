# A bare /slasher offers things to learn about

- **State:** Open
- **Tags:** [idea]

**A bare `/slasher` would offer the engineer things to learn about, through the selection interface: Items, Features, and Experiments.** The engineer could also type something else in. For the selection, Slasher would explain it briefly: selecting Items would run *Briefly explain items*.

Today a bare `/slasher` prints the command domain table, which `/command-table` and `/commands` also print.

**Not yet settled:** whether the bare `/slasher` still prints the command domain table, and which other topics are offered beside Items, Features, and Experiments.

## History

As the engineer first stated it: "A bare \"/slasher\" command offers the user things to learn about: Items, Features, Experiments. The user can also type something in. For the user's selection, for example: items, run \"Briefly explain items\""
