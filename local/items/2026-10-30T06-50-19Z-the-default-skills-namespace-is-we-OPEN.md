# The default namespace for the Waytide skills is `we`

- **State:** Open
- **Tags:** [idea]

**The Waytide skills plugin is named `we`, so its skills are typed as `/we:item`, `/we:log`, and so on, until an engineer chooses another name.** It is the default the item `2026-10-30T06-46-24Z-an-alias-command-names-the-skills-namespace` would replace.

**What a short name risks.** Two enabled plugins with the same manifest name are not namespaced apart: one loads, or one copy's hooks do not run, per the log entry `2026-10-29T20-53-01Z-a-plugin-namespace-is-its-manifest-name-and-is-not-unique-across-marketplaces`. Whether `we` is taken can be checked only in the marketplaces that can be seen.

## History

As the engineer first stated it: "Idea: Default skills alias (plugin name) is we". Asked whether it was "we" or "wt", the engineer selected "we".
