# The status line shows the current implementation and its phase on a second line

- **State:** Open
- **Tags:** [idea]

**The status line would carry a second line naming the current implementation, the feature or experiment under way, and its current phase.** Today the status line is one line: the repository, the branch, and any uncommitted, untracked, or unpushed work. The engineer would see what work is under way, and which step of it, without asking.

**Not yet settled:** which implementation is current where more than one is Active or Suspended, what the second line shows where none is current, and how the phase is shown where the implementation has no phases.

## Settled

- **2026-11-06** — Where more than one implementation is current, the second line shows the one most recently acted upon.
- **2026-11-06** — Where no implementation is current, the status line has no second line.
- **2026-11-06** — Where the implementation has no phases, the second line shows no phase.

## History

As the engineer first stated it: "Idea: The current implementation (and phase) should be displayed on the second line of the status line"

As the engineer stated it, on which implementation is shown: "The one that is most recently acted upon"

As the engineer stated it, on what the second line shows when nothing is current: "The second line should not even display"

As the engineer stated it, on how the phase is shown where the implementation has no phases: "It should not be displayed"
