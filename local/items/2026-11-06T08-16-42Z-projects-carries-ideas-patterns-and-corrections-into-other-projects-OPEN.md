# Projects carries ideas, patterns, and corrections into other projects

- **State:** Open
- **Tags:** [idea]

**`/projects` would help move ideas, new patterns, and corrections from the project the session is in into other Waytide projects on the machine.** Today it only lists the projects in the machine's registry. It changes nothing and acts on no project listed, as the projects-lists-the-machines-registry-of-waytide-projects rule requires.

It bears on the item `2026-10-30T06-57-47Z-commands-can-target-the-machines-root-install-of-waytide`, whose base and system projects would also take records from other projects.

**Not yet settled:** what is carried, such as an item, a rule, or a correction to a rule; whether a carried record is copied or moved, and how its origin is recorded; how a project is chosen from the registry; and how this sits beside the work-in-a-downstream-project-is-never-offered-and-its-pending-state-is-not-reported rule, which keeps the agent from offering work in another project.

## History

As the engineer first stated it, while settling the help text's description of PROJECTS: "To PROJECTS add something like: Helps move ideas, new patterns, corrections into other projects on the machine"
