# Every major root command takes a help subcommand

- **State:** Open
- **Tags:** [idea]

**Each major root skill takes `help` as a subcommand, and prints that command's part of the help text**, such as `/item help` printing the items section. It belongs with the item `2026-10-29T16-24-42Z-waytide-skills`, and with the command protocol, one of the rules the slash-commands phase writes before any skill is built.

**Not yet settled:**

- which root commands are major
- whether the help text is kept in one place and each command prints its own section of it
