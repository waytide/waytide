# The README presents more of Waytide's capabilities

- **State:** Open
- **Tags:** [idea]

**The root README presents more of what Waytide can do.** Today it introduces the rules that direct the agent, the design method, the work recording itself, project-local rules, domain conventions, and the machinery. Then it turns to installing and selecting packages. Capabilities the packages provide and the README does not present would be added, so a reader learns from the README what Waytide makes possible before reading any rule.

**Which capabilities, and how much of each, is not yet settled.**
