# A CSS framework grades a named style with functions such as most() and less()

- **State:** Open
- **Tags:** [idea]

**A CSS framework names a style by what it does, such as `emphatic`, and grades it with custom functions: `most(emphatic)` for the strongest form and `less(emphatic)` for a weaker one.** A writer asks for more or less of a named quality rather than setting the properties that produce it.

**Not yet settled:**

- which functions grade a style beside `most()` and `less()`
- what a named style such as `emphatic` is made of, and how a function changes it
- how the functions are implemented, since CSS has no user-defined functions of this form

## History

As the engineer first stated it: "Idea: A CSS framework with custom functions so that `emphatic` can be modified with `most(emphatic)` less(emphatic)"
