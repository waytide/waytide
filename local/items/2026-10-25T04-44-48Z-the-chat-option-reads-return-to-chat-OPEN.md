# The chat option reads "Return to chat"

- **State:** Open
- **Tags:** [idea]

**The selection prompt's option for leaving the prompt should read "Return to chat", not "Chat about this".** The option takes the engineer out of the selection and back to the conversation, and the new label says that. "Chat about this" names a topic, *this*, that the engineer may not mean to discuss. The engineer met it on 2026-10-24, when a prompt about which log entry to write offered it.

**The option is the harness's, not Waytide's.** Claude Code renders it beside the options the agent supplies, and no rule here sets its wording. The present-every-prompt-through-askuserquestion rule names "Chat about this" only as the example of a free-text option the agent must not add itself.

**Not yet settled:**
- whether the change is a request to the harness's maker, since Waytide cannot set the label
- whether the present-every-prompt-through-askuserquestion rule's example changes to match, or keeps the label the harness actually shows
