# A goal is an item type

- **State:** Realized
- **Tags:** [idea]

**An item may be a goal: an outcome the project means to reach, which other items serve.** Where an idea proposes and a work item is a piece of work to do, a goal names the end the work is for, and stays open until that end is reached or given up.

**Not yet settled:**
- whether a goal is a freeform tag, as `[aspiration]` is, or a reserved type with states of its own, as `[work-item]` is with `Done`
- how a goal differs from an `[aspiration]`, which items-convention already names
- how an item names the goal it serves, and whether a goal lists what serves it
- whether the status report shows goals
