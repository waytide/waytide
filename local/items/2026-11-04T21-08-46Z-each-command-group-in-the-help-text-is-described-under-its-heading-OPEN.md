# Each command group in the help text is described under its heading

- **State:** Open
- **Tags:** [idea]

**Each heading in the help text, `scratch/skills.md`, would carry a short description of its group of commands**, under the heading and above the commands. A heading such as ITEMS, PHASE, or FREEWRITING names the group. The description would say what the commands in it are for, in a line or two, so a reader knows what the group does before reading its commands.

The help text is what a bare `/slasher` is to print, so the descriptions would reach every engineer who asks for help.

**Not yet settled:** the wording of each description, and whether each command's own `help.md` carries its group's description too.

## History

As the engineer first stated it: "New idea: Put short description of a category of commands under its respective heading in skills.md"
