# The engineer can ask the agent how long a task would take them to do

- **State:** Open
- **Tags:** [idea]

**The engineer can ask the agent how long a piece of work would take the engineer to do themselves.** The answer is an estimate of the engineer's own effort, not the agent's. An example is "Can the problems be remedied quickly by me?" The agent answers with what each step is, which steps are the engineer's and which the agent's, and roughly how long the engineer's part would take.

**It serves the choice between doing a thing and handing it over.** A task that takes the engineer a minute is worth doing directly. One that takes an hour of the engineer's attention may be better left to the agent.

**How the agent arrives at an estimate, and how it states its uncertainty, is not yet settled.**
