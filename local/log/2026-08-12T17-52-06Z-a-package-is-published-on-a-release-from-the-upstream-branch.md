# A package is published on a release, from the upstream branch, and never from an experiment or a feature — publishing follows the decision to release a version rather than following a commit, and a release is made on the branch the work merged into, so neither an experiment nor a feature publishes, since neither decides a version and neither has merged; the rare exception is an experiment whose own question is about publishing, and it is put through the selection UI and recorded as a confirmation; `CONTRIBUTING.md` said *after committing a change here, re-publish the affected package*, with no mention of a branch, and that line is corrected
