# The diary's dating rules conflict on an entry carrying no time, which is the ordinary case — the diary-entries rule says the absence of any time reference means the current local date and time, and the ask-for-entry-time-or-omit-it rule says to ask rather than choose a default; what separates them is stated nowhere, since the second is written for an entry about a past event whose time only the writer holds, and the first covers an entry written now about now, so an agent following the two literally asks every time and receives the value the default would have given; recorded as found in the Diary test experiment, and left uncorrected
